# SmartProp

Trao đổi với người dùng bằng tiếng Việt.

## Agent skills

### Issue tracker

Quản lý công việc bằng GitHub Issues tại `manchae19/SmartProp`. Khi tạo, đọc hoặc cập nhật issue/spec, đọc `docs/agents/issue-tracker.md`.

### Triage labels

Dùng 5 nhãn mặc định: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. Khi phân loại hoặc chuyển trạng thái issue, đọc `docs/agents/triage-labels.md`.

### Domain docs

Bố cục single-context: `GLOSSARY.md` và `docs/adr/` tại gốc repo. Trước khi khảo sát mã nguồn hoặc làm việc với thuật ngữ/quyết định kiến trúc, đọc `docs/agents/domain.md`.
